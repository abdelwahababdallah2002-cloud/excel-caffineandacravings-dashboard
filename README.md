# ☕ Caffeine & Cravings — Cafe Sales Data Analysis

## 📌 Project Overview

**Caffeine & Cravings** is an Excel Data Analytics project that analyzes café transaction data to extract meaningful business insights and understand sales performance.

The project covers the complete data analytics workflow, starting from **raw/dirty data**, followed by **data cleaning and transformation**, then analysis and visualization through an Excel dashboard.

## 🎯 Project Objectives

* Clean and prepare raw café sales data.
* Handle missing and inconsistent values.
* Transform the data using **Power Query**.
* Analyze sales and transaction patterns.
* Identify top-performing products.
* Analyze sales by location.
* Compare payment methods.
* Analyze monthly sales trends.
* Build an interactive Excel dashboard.
* Generate actionable business insights from the data.

## 🗂️ Dataset

The dataset contains café transaction records with information such as:

* Transaction ID
* Item
* Quantity
* Price per Unit
* Total Spent
* Payment Method
* Location
* Transaction Date
* Month Name

The cleaned dataset contains **14,928 transactions**.

The original dirty dataset contains **10,000 records** and includes issues such as missing values and inconsistent data that were addressed during the cleaning process.

## 📊 Analysis Areas

The project explores several aspects of café performance:

### Product Analysis

Analyze the performance and sales contribution of different products such as:

* Coffee
* Tea
* Cake
* Cookie
* Sandwich
* Salad
* Smoothie
* Juice

### Location Analysis

Compare transaction activity between different locations, such as:

* In-store
* Takeaway

### Payment Method Analysis

Analyze customer payment preferences across available payment methods.

### Monthly Sales Analysis

Examine sales performance over time and identify monthly trends and changes.
